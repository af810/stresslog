# このフォルダについて（不要ファイルまとめ）

ここにあるファイルは、開発中に別PC環境向けに書いた**一回限りのデバッグ・検証用スクリプト**です。
アプリのビルド・実行には一切不要なので、初めてこのプロジェクトを触る人は無視してください。

## なぜ残っているか

- `install_run.ps1` などは `C:\Users\akimi\Desktop\AndroidDev\Sdk` のような**旧PCの絶対パスを直書き**しており、別環境ではそのまま動きません（詳細は `../HANDOFF.md` の「ハマりどころ」参照）
- `dump_*.ps1` / `tap_*.ps1` / `nav_check*.ps1` は特定タイミングのUI検証・スクリーンショット取得用の使い捨てスクリプト
- `verify*.ps1` はシード投入後のDB内容確認用
- `seed.sql` / `test.sql` / `gen_seed.ps1` / `*.csv` / `*.xlsx` は合成データ生成・投入・エクスポート関連（再現手順は `../HANDOFF.md` の「合成データの再投入」参照）

## 通常の開発では

- Androidアプリのビルド・実行は `../HANDOFF.md` の「ビルド・実行」セクション（`gradlew.bat installDebug` 等）だけで完結します
- ここのスクリプトを使う必要が生じたら、パスを自分の環境に書き換えてから使ってください
