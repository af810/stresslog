# 運動による急変を抑え、持続するストレス反応を捉える方式案

検討日: 2026-11-17。**本書は当初の設計案。現在は一部に絞った比較用試作を別アプリとして実装した。現行アプリの計算は変更していない。** 実装した範囲・差分・評価結果・起動手順は [STRESS_COMPARISON.md](STRESS_COMPARISON.md) を優先する。設計案全体を実装・検証済みという意味ではない。

使用者の要望は、運動やノイズによる急変を抑え、実際の強いストレスによる変化を捉えること。体感入力・本人の事前基準登録を不要とする既存の条件を維持する。数値が時々跳ねるように調整したり、イベントの発生回数を人為的に増やしたりしない。通知は今回の対象外。

## 現在の方式との違い

現行方式は、WESADの出力を別の身体活動判定で保留する。これは運動由来の値をストレスと表示する問題を減らすが、保留区間に本当のストレスがあったかは分からない。高値の減少自体は検出精度の改善を意味しない。詳細は [ACTIVITY_CONTEXT.md](ACTIVITY_CONTEXT.md)。

今回の候補は、**活動から予想される反応とのずれを特徴量にし、品質と時間経過を含めて学習する方式**。この組み合わせ全体を検証した論文があるという意味ではない。以下の研究から考え方を取り入れ、本プロジェクトで新たに構築・検証する。

採用根拠は「成功率を転用できるから」ではなく、活動・回復・品質・持続時間をそれぞれ検証すべきことが示されているため。

## 具体的な計算案

### 1. 信号品質と活動を分けて記録

PPG、心拍、ACCの同期、欠測、脈波の段差、拍動の品質、心拍との整合を評価する。単に値が大きい・変化が急という理由で除去しない。品質不足と本当の変化を混同しない。

特徴量は、心拍中央値・ばらつき、信頼できる区間のln(RMSSD)などのPRV、ACCのENMO・jerk・周期性、過去の活動量。手首ACCから全身の姿勢や運動強度を確実に判別できるとは仮定しない。活動不明を明示する。

候補は**過去120秒の窓を30秒ごとに更新**。運動後の影響を扱うため過去5–10分の活動履歴も入力する。いずれも本プロジェクトの検証候補で、論文がこの設定の優位性を証明したわけではない。未来のデータは使用しない。

### 2. 活動で説明できる反応を推定

活動の特徴と過去の履歴を `A[t]` とする。公開データの安静・運動・回復区間を使い、母集団で共通の予測モデルを学習する。

```text
予測心拍       = f_HR(A[t], A[t-1], …)
予測lnRMSSD   = f_PRV(A[t], A[t-1], …)

心拍のずれ     = 実測心拍 − 予測心拍
PRV低下のずれ  = 予測lnRMSSD − 実測lnRMSSD
```

予測の不確かさも学習し、誤差を予測分布の尺度で扱う。平均推定の標準誤差を、そのまま新しい人の予測誤差とみなさない。予測範囲を外れる活動や信号は判定困難とする。

**このずれ単独をストレス値にはしない。** 発熱、カフェイン、姿勢、体力差、呼吸、測定誤差なども残り得る。運動モデルの予測漏れも心理的ストレスに見える。先行研究の個人別モデルを母集団モデルへ変更すること自体が新たな仮説である。

### 3. ずれとPRVからストレス候補を学習

上記のずれ、信頼できるPRV、活動・回復状態、欠測マスクを入力し、公開データの実験条件を教師に「ストレス課題に近い反応」を学習する。単純に心拍へ正の重み、HRVへ負の重みを付けた手作りの合算式にはしない。

PRVあり／なしで、突然別スケールの値に切り替わらないよう、欠測を扱う学習と出力の整合性を検証する。PRVなしのモデルが同程度の検出性能を持つとは仮定しない。品質条件を弱めて見かけのデータ量を増やすこともしない。

出力は必要なら被験者を分けた予測で校正するが、0–100の値を心理的ストレスの絶対量や実生活の発生確率とは呼ばない。

### 4. 表示値と変化の判定を分ける

短時間の生出力とは別に、過去のみを使う時間統合を行う。候補は品質で重み付けした指数平滑化と、上昇・解除で異なる閾値を使う状態判定。

```text
alpha = 1 − exp(−更新間隔 / 時定数)
表示用の内部値[t] = q[t] * alpha * 生出力[t]
                 + (1 − q[t] * alpha) * 内部値[t−1]
```

`q[t]` は観測品質に由来する0–1の重み。品質不足・活動不明・学習範囲外の間は新しいストレス判定を行わず、古い内部値を現在の測定値として表示しない。欠測を0や平常として埋めない。運動中の滑らかな線を生成できても、妥当な推定を得たことにはならない。

平滑化の時定数60–120秒、変化確認に必要な有効観測時間60–120秒などを比較候補とする。値・時間・閾値は独自の設計候補であり、今ここで最適と確定しない。上昇候補を早めに記録し、持続時に確定する二段階を検討する。

重複する120秒窓の数を独立した証拠の数として数えない。過去30秒で実際に増えた有効データの時間と欠測を管理する。通信が切れたまま候補が確定してはいけない。

急変の上限固定や単純な移動平均だけでは、運動による高値を後からゆっくり高値にするだけになる。身体活動の扱いと信号品質を先に検証する。

## データと検証

- 公開データ候補は [Hongn et al.のデータv1.0.1](https://physionet.org/content/wearable-device-dataset/1.0.1/)（DOI 10.13026/he0v-tf17、ODC-By 1.0）。安静・ストレス課題・自転車運動／回復を含む。手首BVPを使い、可能な限り本番と同じ特徴量・品質判定で再処理する。
- [WESAD](https://ubi29.informatik.uni-siegen.de/usi/data_wesad.html) は追加のストレス課題データとして検討。科学研究・非商用用途等の利用条件を維持する。ECGから得たHRVと手首PRVは同一視せず、主評価は実際に利用するモダリティで行う。
- [Wrist PPG During Exercise](https://physionet.org/content/wrist/1.0.0/) は歩行・走行・自転車の外部チャレンジに使う。運動のみなので、これだけでストレス検出精度を評価しない。
- ストレスと運動が同時に発生する場面、手作業、姿勢、時刻・機器差は別の検証が必要。学習データに該当場面がなければ、分離できるとは主張しない。
- 同一人物の全セッションを同じ組にし、被験者単位で学習・調整・評価を分離。予測心拍／PRVモデルもその内側で学習する。正規化や校正にも評価対象のデータを漏らさない。重複する時間窓をランダム分割しない。
- 現行方式、平滑化だけの方式、新方式を比較。窓ごとの正答率に加えて、運動時の高値表示率、参照イベントの検出率、誤検出回数/時間、検出の遅れ、出力できる時間の割合、PRVの採用率、モデル切替時の飛びを評価する。保留の多さを必ず併記する。
- 心拍・PRV・ACC集計・品質・モデル分岐・活動状態を時刻付きでローカル保存できるようにする。原因の検証に必要な情報であり、個人データとしてGit管理外に置く。今回はまだ保存項目を変更していない。

## 採用条件と限界

目標は、運動による誤反応を減らしながら、ストレス課題の検出率を維持できること。先に数値目標と評価手順を決め、公開データで現行方式と比較してから実機へ進める。今回の使用者データで見栄えが良くなるよう閾値を決めない。

本人の事前データなしで実行すること自体は可能だが、個人ごとの安静心拍・PRV・体力差を補正する情報は少なくなる。自動で蓄積した個人基準へ将来切り替える場合は、条件変更として別途説明する。

時間をまとめるほど、短いノイズには強くなる一方、短い本当のストレス反応も見逃し得る。120秒の観測窓と持続確認を併用すれば検出に数分かかる場合がある。今回の案がすべての真の急変を保存できる保証はない。

PRVを安定して取得できない区間が多ければ、HRV主体の方式は情報不足になる。時計PPGでの拍動間隔の品質と有効時間を先に確かめる必要がある。脈波を高い周波数へ補間しても、新しい測定情報が増えるわけではない。数値を出せることと、心理的ストレスを正しく区別できることは別に評価する。
